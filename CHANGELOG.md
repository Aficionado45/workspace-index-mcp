# Changelog

## 0.1.0 — 2026-10-09

- Added a standalone Rust MCP server and CLI with explicit multi-workspace registration, read-only defaults, XDG paths, SQLite migrations, and a single-owner data-directory lock.
- Added ignore-aware scanning, tree-sitter language adapters, line-window chunking, SQLite/FTS indexing, local FastEmbed support, and a rebuildable usearch cache adapter.
- Added lexical, symbol, and stored-vector retrieval with signed cursors, citation freshness checks, and bounded tool output.
- Added notify-based workspace watchers, branch/HEAD observation, queue coalescing, periodic manifest reconciliation, and visible-generation transitions.
- Added capability-scoped reads and two-phase changeset preparation/status with private payloads, per-file intent/effect journaling, recovery classification, and durable reindex jobs; source effects remain unavailable until containment is proven.
- Added rmcp stdio tools/resources/prompt, generated omp approval policy, static `omp-config`, and CLI confirmation gates.
- Added append-only SQLite v4 generation/profile watermarks, durable path queues, stable numeric vector IDs, and synchronous FULL state connections.
- Added v5 tombstoned workspace registration epochs, gix linked-worktree identity, registered-root binding, and strict relative-path checks. Source mutation returns `UNSUPPORTED` on all platforms because descriptor-relative rename/unlink cannot rule out a concurrent parent-directory relocation.
- Hardened search cursors against UTF-8 slicing panics and oversized inputs; graph cursors now bind to exact graph content, and parsed/sorted graph snapshots are reused within a bounded cache.
- Added real stdio resource-subscription lifecycle coverage for updates, unsubscribe, invalid resources, and the subscription cap. `omp-config` explicitly documents its non-concurrent user-owned directory assumption.
- Hardened optional Graphify extraction: Linux runs Graphify in bubblewrap user/PID/network namespaces with a cleared environment, no inherited file descriptors, read-only allowlisted staging/runtime binds, mountinfo-aware workspace-alias rejection, bounded private tmpfs output/home/temp, and a 120-second ceiling. Missing sandbox support and explicitly requested disabled/failed Graphify report non-retryable `GRAPH_UNAVAILABLE`; other platforms fail closed.
- Added typed FastEmbed/Ollama/OpenAI-compatible provider construction, immutable configuration-fingerprinted profiles, dual-profile reconciliation, durable Sequencer HNSW synchronization and ProfileManager promotion, startup cache recovery, and per-workspace semantic query routing with profile-bound cursors.
- Made durable reconciliation job state transitions coalesce duplicate queued, running, and completed rows, so repeated full reconciliations remain safe under the per-path state uniqueness constraint.
- Added bounded stale-candidate refresh/retry for code and symbol search, SHA-256 citation hashes, frozen ranked search cursors with explicit result-cap termination, branch-transition graph/startup gates, and verified-watermark-only profile promotion.
- MCP blocking operations remain tracked after caller cancellation; `index_status` exposes active operations and workers retain the service owner lock through completion.
- Watchers now treat an absent Git marker as stable for permitted non-Git roots, detect persisted branch changes before startup admission, and refresh ordinary changed paths without rescanning unchanged files; failures still queue full reconciliation.
- Refused indexed/read file descriptors with multiple hard links, rejected control characters in changeset paths, and preserved missing-final-newline markers in approval diffs; source mutation remains disabled.

- Watcher stop/drop now waits at most two seconds; still-running watcher handles remain in a process-wide registry capped at 128, and a root cannot start another watcher until its prior worker exits. Every watcher loop exit durably queues a full reconciliation before releasing its backend, including otherwise clean stops, covering notifications racing callback teardown. Directory creation/removal and rename events request full-tree reconciliation. Stale-search and post-write refresh/retry share one tracked worker per service; synchronous provider/filesystem calls are not forcibly interrupted and timed-out work may continue.
- Ignore recursive-watcher registration events for the workspace root itself; child directory creation/removal and rename events still request full reconciliation.
- Added append-only SQLite v8 archives for unregistered changesets, retaining terminal status, per-file paths/hashes/states, and audit evidence without private source text. Workspace deletion now commits its archive and a payload-cleanup queue atomically; exact UUID payload unlinks are directory-synced and retried on startup/doctor, including terminal and failed-prepare cleanup.
- Malformed payload-cleanup IDs trigger a bounded, fail-closed scan of canonical UUID payload files; only `Prepared`/`Applying` rows and cleanup records pin payloads. Handle-relative enumeration, metadata, unlink, and directory sync precede queue retirement. Schema v9 persists a recovery target before unlink so sync/row-delete retries converge; absent or ambiguous orphans remain visible in `doctor`. A same-UID process can still race replacement of a directory entry between metadata and unlink.
- Graphify extraction now publishes only after generation, registration epoch, and root-identity rechecks under the per-root mutex. Graph paths/cache/cursors/status are epoch-bound; source hashes are revalidated before reads, failed current-generation extraction returns no nodes, and unregister invalidates old graph state. Timed-out watchers retain the service long enough to queue durable shutdown reconciliation.
- Watcher stop outcomes distinguish clean thread exit from shutdown-reconciliation enqueue failure. Unregister remains registered and attempts watcher restart on durable queue failure; server shutdown reports and logs persistence failures without exceeding the shared two-second stop deadline.
- Unregister now restarts a watcher inside its blocking worker when shutdown reconciliation persistence fails, so cancellation cannot leave a registered workspace unwatched; timed-out handles are reinserted before returning.
- Added append-only SQLite v10 index `idx_chunk_embeddings_semantic_lookup` for workspace/profile/numeric-vector/generation semantic candidate lookups.
- FTS rank queries are forced to start from the `MATCH`-constrained FTS5 index before rowid/file/state joins; BM25 order, visible-generation checks, and post-filter limits remain unchanged. An EXPLAIN regression protects the plan; the local synthetic benchmark is recorded in the README.
- Semantic candidate mapping now degrades the workspace on invalid HNSW IDs, duplicate numeric-ID rows, and malformed database metadata; genuinely stale/non-visible rows remain omitted.
- Known limits: source changes can be prepared but not applied; Graphify and remote provider requests remain opt-in; cloud-scale Augment parity and retrieval-quality thresholds are not claimed. The synthetic retrieval p95 is recorded in the README and does not guarantee production latency.
